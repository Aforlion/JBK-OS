# Pilot Success Metrics & Service Level Objectives

To evaluate the success of the JBK-OS pilot program, we track several technical and business performance indicators.

## 1. Service Level Objectives (SLOs)

We define the following Service Level Indicators (SLIs) and target SLOs for pilot client instances:

| Indicator (SLI) | Definition | Target (SLO) | Error Budget |
| :--- | :--- | :--- | :--- |
| **Availability** | HTTP Status 200 responses to Uptime Checks over a calendar month. | >= 99.9% | < 43 mins outage/month |
| **Latency** | 95th percentile of response times for API requests. | < 2.0s | N/A |
| **Intake Success** | Percent of unstructured intake briefs successfully classified. | >= 95% | 5% failure rate |
| **Deployment Time** | Time to provision a new client environment from checklist. | < 30 mins | N/A |

## 2. Business KPIs (Key Performance Indicators)

We evaluate pilot performance against these business goals:

- **Time Saved**: Percent reduction in manual estimation and proposal generation time (target: >80% reduction).
- **Task Allocation Accuracy**: Percent of task assignments requiring manual overrides (target: <10%).
- **User Adoption Rate**: Active daily/weekly logins by managers and executives (target: >75% weekly active users).

## 3. Customer Satisfaction (CSAT)

- **Pilot Review Sessions**: Conduct bi-weekly reviews with pilot stakeholders.
- **CSAT Survey**: Issue a survey at the end of the pilot phase (target score: >= 4.5 / 5.0).
